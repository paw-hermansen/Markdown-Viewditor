# App Name Selection

## Chosen Name: **MarkEdiViewer**

### Why This Name?

**MarkEdiViewer** combines three key concepts:

- **Mark** - From "Markdown"
- **Edi** - From "Editor"
- **Viewer** - From "Viewer/Preview"

The name clearly communicates what the app does: it's a markdown editor and viewer with **live preview**.

### Name Characteristics

- ✅ **Unique** - No existing software with this name
- ✅ **Descriptive** - Clearly indicates markdown editing and viewing
- ✅ **Modern** - Clean, compound word style
- ✅ **Memorable** - Easy to pronounce and remember
- ✅ **Professional** - Suitable for both personal and commercial use

### Tagline Suggestions

- "Write beautifully, see instantly"
- "Your markdown, live"
- "Edit. Preview. Perfect."
- "Where writing meets preview"

## Conclusion

**MarkEdiViewer** is the chosen name because it:

1. Clearly describes the app's function
2. Is unique and memorable
3. Hints at markdown, editing, and viewing
4. Is professional and modern
5. Works well as a brand name

The name perfectly captures the essence of the app: a markdown editor with **live preview**.
