## Description

Advanced extended markdown viewer and editor with scroll sync, custom themes, Mermaid diagrams, math
and chem formulas, "SKILL.md" handling, and several exports. Write markdown on the left, see the
rendered result on the right — updated in real-time as you type.

Whether you're writing documentation, notes, technical papers, or blog posts, Markdown Viewditor
gives you a clean, distraction-free editing experience with powerful features built in. Choose from
three view modes: editor-only, split view, or preview-only. The scroll sync keeps your cursor
position and preview aligned automatically.

Render mathematical formulas and chemical equations with built-in KaTeX and mhchem support —
including delimiters used by ChatGPT, Claude, Copilot, and Gemini, so you can paste AI-generated
math directly into your documents.

Render flowcharts, sequence, gantt, class, state, and 10+ other Mermaid diagram types directly from
mermaid code blocks. Diagrams automatically follow the app's light/dark theme.

Customize the look with 8 built-in dark and light themes, or create your own with custom CSS. Export
your work to self-contained HTML, ODT (for Word, LibreOffice, and others), or print to PDF. HTML and
PDF export can be fully themed including custom themes.

Markdown compatibility levels let you target basic (CommonMark), GitHub-flavored, or advanced syntax
— with soft editor warnings when your document uses features outside the chosen level.


## Product features

- Three work modes: editor, split, and view
- Scroll sync between editor and view
- 8 built-in dark and light themes + Printer Friendly theme
- Custom CSS theme support
- App zoom (70%–300%)
- Markdown compatibility levels (Basic, GitHub, Advanced, Custom) with soft warnings in editor
- Mermaid diagrams: flowcharts, sequence, gantt, class, state, and 10+ other diagram types
- Math formulas via KaTeX with support for ChatGPT, Claude, Copilot, and Gemini delimiters
- Chemical equations and physical units via mhchem
- YAML frontmatter and SKILL.md files support
- Raw HTML
- Export to self-contained HTML, packaged HTML, and PDF using themes
- Export to ODT and ODT with math/chem/diagrams/SVG as PNG with printer-friendly theme
- Open source in github project, MIT License, always free
- Available for Windows, Mac, and Linux
